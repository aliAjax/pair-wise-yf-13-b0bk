# hxyfront-62001 临时旁路许可台 · 船舶轮机值班

在原船舶轮机值班记录页基础上改造的**临时旁路许可台**，为主机、发电机、泵组登记旁路许可。

## 业务规则

- 登记旁路需填写**旁路原因、责任人、到期班次**（另可登记签发时的基线读数）。
- **同一设备最多一条有效许可**；设备必须存在**未处理异常**才能登记旁路。
- 缺原因 / 缺责任人 / 缺到期班次、设备已有有效许可、设备没有未处理异常 —— **整次拒绝**，原参数读数与既有许可保持不变。
- 许可随值班班次推进自动判定状态：当前班次超过到期班次即为到期。
- 到期后该设备**读数登记锁定**：看板、筛选角标、交接班摘要、历史记录均同步标出 🔒。
- **续期必须补录复测值**，否则拒绝续期、锁定不变；补录后续期成功并解锁，续期记录留存。
- 异常消除后可关闭有效许可。
- 数据保存在浏览器 `localStorage`，刷新后保留；页内"恢复演示数据"可重置。

## 架构（数据模型 / 状态流转 / 页面组件分层）

```
src/
├─ model/
│  └─ types.ts            # 数据模型：设备/读数/异常/旁路许可/班次/事件
├─ state/
│  ├─ transitions.ts      # 状态流转：纯函数校验规则 + 状态判定(active/expired/closed/锁定)
│  ├─ reducer.ts          # 原子提交：校验不过返回原状态；含种子数据
│  ├─ store.tsx           # React Context store + localStorage 持久化
│  └─ selectors.ts        # 看板指标、筛选、交接班摘要派生数据
├─ components/
│  ├─ ui.tsx              # 通用组件：Panel/Badge/Notice/班次标签
│  ├─ Board.tsx           # 班次切换、参数看板、设备筛选(带锁定角标)
│  ├─ PermitDesk.tsx      # 许可登记表单 + 许可台账(续期/关闭)
│  ├─ Operations.tsx      # 读数登记(锁定拦截) + 异常巡检时间线
│  └─ Summary.tsx         # 交接班摘要(导出) + 历史记录
└─ App.tsx
```
