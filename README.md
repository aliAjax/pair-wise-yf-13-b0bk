# hxyfront-62001 临时旁路许可台

源提示词编号：1

在船舶轮机值班记录页基础上改造的临时旁路许可台：为主机、发电机或泵组登记旁路原因、责任人和到期班次。

## 业务规则

- 同一设备最多一条有效许可；登记时缺旁路原因/责任人/到期班次、已有有效许可、或设备没有未处理异常，整次拒绝，原参数与许可不变。
- 当前班次到达许可的到期班次后，许可转为已到期，设备锁定读数登记；交接摘要与设备筛选同步标出锁定。
- 续期必须补录复测值并选择新的到期班次，否则锁定不变。
- 数据保存在浏览器 localStorage，刷新后保留。

## 代码结构

- `src/model/types.ts` — 数据模型（设备、许可、续期、异常、读数）
- `src/model/transitions.ts` — 状态流转（纯函数：登记/续期/读数/异常/班次切换）与派生状态选择器
- `src/model/seed.ts` — 初始演示数据
- `src/store/usePersistentState.ts` — localStorage 持久化
- `src/components/` — 页面组件（班次切换、设备状态、许可登记、许可台账、异常时间线、读数登记与筛选、交接摘要）
